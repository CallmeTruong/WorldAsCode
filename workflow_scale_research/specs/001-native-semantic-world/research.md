# Research decisions

The skill is an agent protocol plus scripts, not a one-call API. Native next/state, strict spec, ordered passes and append_review must remain authoritative. Reuse commands, not a truncated prose summary. Native generic profile is applicable to architectural hard-surface assets; do not claim an installed urban plugin exists.

The new semantic compiler is complementary: it supplies typed object structure, runtime bindings and scale invariants. It does not mark upstream stages complete. Hollow geometry is a material shell around an empty channel; manifold integrity alone is not a cavity test. Native extrude supports holes, so this can be represented without bypassing the upstream factory.

Arbitrary style images guide geometry/detail/shading, not a fixed palette. Approximate finishes are allowed by user scope; material/projection applicability must be explicit. Multi-angle evidence and per-feature blockers remain required.

No quality parity can be inferred from repository demos. Compare actual source/render evidence under pinned versions. Road/rail network seams, seed channels and runtime state are separately testable before deployment at city scale. The initial implementation uses a local artifact/job backend; distributed infrastructure is deferred until throughput is measured.
# Follow-up research: native factory contract and pilot

The pinned factory reads `transform.scale` before `dimensions`. A unit identity scale therefore overrides authored physical dimensions even though the native strict validator accepts the spec. This was confirmed against the generator source and the Tokyo blockout output (IoU 0.307, scale delta 0.591). The implementation records removal of identity scale only when positive dimensions exist, then verifies the real native strict validator and generator. A controlled post-fix browser preview still scored 0.346 in camera silhouette fitting, so the contract fix is necessary but does not establish fidelity.

Hard deterministic rejection is routed through the pinned `correction_loop.decide`; this returns `refine-code` for Divine Eye hard gates. Meso/micro part checks are scoped to passes that actually build them; final coverage remains whole-spec. Current Tokyo requests exhausted a configured 12-call budget (two HTTP 524 outcomes, whose billed use is uncertain), so no new model repair was submitted.
