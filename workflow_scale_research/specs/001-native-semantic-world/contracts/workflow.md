# Workflow contracts

Observer emits source-grounded macro/meso/micro observations and uncertain classifications. Spec author consumes native assessment/starter/schema and gate errors, producing ObjectSculptSpec plus semantic overlay. Native bridge runs next before each transition and records stdout/stderr, hashes and exit status. Strict failures go to refine-spec.

Generator executes only the currently unlocked native pass. Renderer returns meshes, part IDs and multiple camera captures with source hashes. Deterministic gates precede critic requests. Critic returns native action, global/layer/feature scores and evidence; append_review and pass check are called with actual artifacts. Stop/request-input are terminal pending states, not approval to skip.

Runtime/compiler contracts forbid material-only changes from mutating geometry keys, seed changes from moving evidence-locked anchors and tile boundaries from resetting network phase. Publish requires consistent source/spec/render/review hashes. Unsupported simulation capabilities are declared, not silently emulated as factual behavior.
