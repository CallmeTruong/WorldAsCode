## Constitution Check
Evidence first; native gates not bypassed; semantic correctness separate from pixels; deterministic reuse; no secrets in artifacts; no fake quality parity; modules remain independent from legacy package. Pass.

## Phase 0 - Research
Read the native router and phase-specific contracts; pin the upstream commit and hash its relevant files. Map requirements to actual forge commands. Inspect the factory implementation as well as the validator. The Tokyo pilot showed why: the strict validator accepted identity `transform.scale` next to meaningful `dimensions`, while the factory prioritized scale and baked unit-sized geometry. Record this producer/consumer mismatch as a workflow contract, and preserve the failed render and native gate output.

## Phase 1 ? Contracts
World/asset/part/state schemas, native command adapter, artifact/seed/network invariants. See data-model.md and contracts/workflow.md.

## Phase 2 - Implementation
Independent package/config/provider; job/cache ledger; native bridge with verified command exit codes; semantic IR/compiler and hollow/roof/facade generators; sandbox renderer and deterministic probes; node-driven native spec/pass runner and browser demo. Add a consumer-contract preflight for actual factory fields, a lossless identity-scale normalization, and current-pass part coverage. Hard-gate feedback must use the pinned native correction-loop function and preserve its bounded action.

## Phase 3 - Validation
Meaningful negative/positive tests; execute native strict validation, factory generation and browser capture against a bounded actual reference; run the browser semantic/state slice and inspect comparison images. Record tokens, unknown billing, time, each gate and the screenshot. Update per-task completion from execution evidence, not from file existence. A technically successful browser render does not satisfy visual acceptance.

## Post-design Check
No alternate mesh generator silently replaces the native path. Semantic compiler is an explicit complementary path. Both share semantic/evidence contracts and report origin. The current pilot still fails native visual gates and exhausted its call budget before correction. Full skill-quality parity and city throughput require further measured acceptance.
