# World Scale Research Constitution

I. Evidence and native gate authority: no pass or quality claims without actual artifacts; upstream hard stops are not bypassed.
II. Semantic structure: visually plausible solids do not satisfy cavity/opening/attachment contracts by themselves.
III. Determinism and reuse: blueprint, instance and runtime state are separate; versioned seed channels and cache dependencies are explicit.
IV. Independent implementation: new package does not import legacy application code; shared upstream is pinned and audited.
V. Validation and transparency: negative tests, browser evidence and critic/coder separation; technical validity and visual acceptance are reported separately.
VI. Resource discipline: bounded paid calls, no ambiguous retries, no secrets in artifacts; local research before distributed complexity.

Governance: changes record reason and migration impact. User instructions control task scope. Version 1.0.0, ratified/amended 2026-11-12.
